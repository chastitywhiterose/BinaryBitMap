# BinaryBitMap

A collection of C code for managing images using only the C standard library.

The original home of this project was on SourceForge

https://sourceforge.net/projects/binary-bit-map/

There was never a complete goal for the project but it was a library I experimented on and made a few cool animations with. The code may be an unreadable mess but it still works very well for the things I have done with it.

At some point, might still want to use it or maybe rewrite parts of it for smaller projects. Everything works by creating either still image files or multiple frames for animations.
