The Binary Bit Map Plus Plus library is a personal experiment to see if using a C++ style class provides benefits over my traditional way of pure C code.

The goal will be much smaller than my C version of the project was but there will be several features.

Class constructors that create image of the desired size.
Function that fills the image with a checkerboard of any two colors.
Function that draws a single pixel at a given location.
Function that draws a line. //From the Bresenham method.
Function that draws a regular polygon.

As far as other features such as writing different formats of bitmap files, they are the most time consuming things to write but are not completely impossible. I will see how it goes.
